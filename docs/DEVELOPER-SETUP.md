# Developer Setup

## Prerequisites

- **Node** 20+ or Bun 1.1+
- **Docker** (for backend + Postgres)
- **Git**

## Frontend

```bash
git clone <repo>
cd <repo>
bun install
cp .env.example .env
bun dev              # http://localhost:8080
```

### Useful scripts

| Command                | Purpose                                     |
| ---------------------- | ------------------------------------------- |
| `bun dev`              | Vite dev server with HMR                    |
| `bun run build`        | Production bundle                           |
| `bun run build:dev`    | Preview-mode bundle (used by hosting)       |
| `bun run preview`      | Serve the production bundle locally        |
| `bunx tsgo --noEmit`   | Fast TypeScript check                       |
| `bunx eslint src`      | Lint                                        |
| `bunx vitest run`      | Unit tests (once test config is wired)      |

## Backend

```bash
cd backend
docker compose up --build      # brings up API + Postgres + Redis
```

Environment variables live in `backend/.env` (never commit real secrets).

Migrations:

```bash
docker compose exec api alembic upgrade head
docker compose exec api alembic revision --autogenerate -m "add foo"
```

## Mock mode

The frontend can run without the backend by setting `VITE_MOCK_MODE=true` in
`.env`. All module services short-circuit to fixtures in `src/lib/mock/`.
Use this for pure UI work.

## Working conventions

1. **Types first**: add or extend a type in `src/types/*` before writing the
   service method.
2. **Loader primes cache; component subscribes**: never `useEffect + fetch`
   for initial render.
3. **Never re-declare permissions**: import from `@/constants/rbac`.
4. **Never call `fetch` directly**: go through the module service, which
   goes through `apiService`.
5. **Do not edit `src/routeTree.gen.ts`**: it's regenerated by Vite.
6. **Do not edit shadcn primitives in `src/components/ui/*`**: extend them
   in `src/components/common/*` instead.

## Debugging tips

- **Blank page after route change**: verify the parent layout route renders
  `<Outlet />`.
- **Type errors on `Route.useLoaderData()`**: probably editing a route file
  that also uses TanStack Query — read data via `useSuspenseQuery`.
- **`Unauthorized` in prerender**: a public route's loader is calling a
  protected server function — call from the component instead.
